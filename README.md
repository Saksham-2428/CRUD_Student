# 📘 Student Management CRUD Application

A simple **RESTful Student Management System** built using **Spring Boot**.  
This project provides APIs to **Create, Read, Update, and Delete** student records such as name and course.

---

## 🔥 Features
- Add new student details
- Fetch list of all students
- Update student information using ID
- Delete a student record
- Lightweight and easy to extend

---

## 📁 API Endpoints

| Method | Endpoint            | Description                     |
|--------|---------------------|---------------------------------|
| POST   | `/students`         | Create new student              |
| GET    | `/students`         | Get all students                |
| PUT    | `/students/{id}`    | Update student by ID            |
| DELETE | `/students/{id}`    | Delete student by ID            |

---

## 🛠 Tech Stack
- **Java**
- **Spring Boot**
- **Maven**
- **REST API**
